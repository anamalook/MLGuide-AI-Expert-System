# 🧠 MLGuide AI — Intelligent ML Decision Lab

### A Rule-Based Machine Learning Algorithm Recommendation Expert System

MLGuide AI is an educational expert system developed using Python and Streamlit. It helps users identify suitable starting-point machine learning algorithms through an explainable IF–THEN rule-based recommendation approach.

## Project Overview

Selecting an appropriate machine learning algorithm can be challenging for beginners. MLGuide AI simplifies this process by evaluating user-defined requirements and suggesting relevant algorithms with explanations.

## Key Features

- Interactive Streamlit web dashboard
- CSV dataset upload and exploration
- Dataset statistics and feature visualization
- Classification, Regression, and Clustering support
- Rule-based algorithm recommendations
- Algorithm ranking and comparison
- Transparent explanations and limitations
- Downloadable recommendation reports

## Expert System Architecture

**Knowledge Base:** Contains information about supported algorithms, tasks, data patterns, interpretability, and computing requirements.

**Inference Engine:** Matches user requirements against predefined rules and ranks relevant algorithms.

**Explanation Facility:** Explains why each algorithm is recommended and highlights important limitations.

**User Interface:** A Streamlit dashboard for dataset exploration and recommendations.

## Technologies Used

- Python
- Streamlit
- Pandas
- Rule-Based Artificial Intelligence

## How to Run

Install the dependencies:

```bash
pip install -r requirements.txt
```

Launch the application:

```bash
streamlit run app.py
```

## Important Note

MLGuide AI is an educational decision-support system. It does not train machine learning models or measure actual model accuracy. Recommendations are based on predefined expert rules.
